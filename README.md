# Projeto de Estudo em JavaScript 🚀

Este repositório contém uma coleção de exercícios e projetos desenvolvidos durante meus estudos de JavaScript. O objetivo é consolidar conhecimentos fundamentais da linguagem, praticar lógica de programação e explorar recursos do DOM, eventos, funções, estruturas de controle e manipulação de elementos HTML e CSS.

## 📁 Estrutura do Projeto

- `aula13/`: Ambiente de testes com arquivos HTML e JS para prática de conceitos básicos.
- `ex015/`: Projeto interativo que identifica idade e gênero com base em dados inseridos pelo usuário.
- `exercicio1.html/`: Exercício com manipulação de imagens e estilos conforme o período do dia.
- PokeAPI Project: Projeto integrador usando JavaScript assíncrono e iteradores.

## 🧠 Conceitos Abordados

- Manipulação do DOM
- Eventos em JavaScript
- Condicionais (`if`, `else`)
- Funções e escopo
- Interação com elementos HTML
- Estilização com CSS
- Uso de imagens dinâmicas

## 📌 Requisitos

Para visualizar os projetos, basta abrir os arquivos `.html` em um navegador moderno como Chrome, Firefox ou Edge.

## 🛠️ Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript (ES6+)

## 📚 Objetivo

Este projeto é parte do meu processo de aprendizado contínuo em desenvolvimento web. Cada exercício representa um passo na construção de uma base sólida em JavaScript.
